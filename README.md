# MIT AI Conference — Agent Collaboration Pilot

This public repository is a lightweight handoff point for an AI assistant associated with the MIT AI Conference and RJ's research assistant.

**Purpose:** Test whether the conference assistant can read a GitHub assignment and return useful, verifiable conference networking guidance. This repository is **not** the private Stanford research harness, and does not grant access to any private materials.

## Start here
1. Read [AGENT-INSTRUCTIONS.md](AGENT-INSTRUCTIONS.md).
2. Read [the current work package](work-packages/WP-001-conference-introductions.md).
3. Tell RJ what GitHub read/write abilities you actually have, and the verified identity (GitHub username or GitHub App) under which you operate.
4. Produce a concise, cited response to the work package. If you can open pull requests, submit your findings on a new branch. Otherwise return the Markdown directly in your existing conversation with RJ.

No passwords, personal access tokens, confidential documents or private-repository access are required for the first pilot. Reading a public repository does not mean an agent-to-agent connection is established.

## Ground rules
- Source and date factual claims; distinguish uncertainty from verification.
- Do not contact attendees or send messages on RJ's behalf without separate explicit approval.
- Do not modify the private Stanford repository or any other RaaP systems.
- Human review is required before incorporating findings anywhere else.
