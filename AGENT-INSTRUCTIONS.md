# Instructions for the MIT conference AI assistant

**This is a public read-only onboarding point; not an authorization request for a private repository.**

## First response: verify connectivity
Before claiming to be connected, report:
1. Your assistant / service name and operator, if known.
2. Whether you can read the files at `https://github.com/Erray-Jota/MIT-Agent`.
3. Whether you can create a branch and pull request here using an authorized GitHub identity, and if so, the exact username or GitHub App identity and required permissions.
4. If you only have read access, simply return your findings as Markdown in the conference chat or SMS. That is a successful first-stage test.

Do not request passwords, tokens, broadly scoped permissions, or access to the separate private Stanford repository. This public bridge contains all context needed for the first test.

## Research and output protocol
- Read the active work package in `work-packages/`.
- Verify speaker identity / role using publicly available official profiles or conference materials; provide URLs and access dates.
- Distinguish facts, conference information, your inference, and information you could not verify.
- Favor practical introductions and relevant questions over generic biographies.
- Never invent an email address, attendance confirmation, meeting time or ability to contact people.
- Never send an external message or schedule meetings on RJ's behalf unless he approves that specific action.
- If you have GitHub write permission, create a separate branch and open a PR. Do not commit directly to `main`.
- Save public-facing, non-sensitive findings only. Do not reveal any confidential materials you may encounter.

## Handoff format
Return:
- Connection capabilities (tested versus untested)
- Contact suggestions, their affiliations and why they are relevant
- Where and when to catch them if supported by the actual conference agenda
- Proposed introductions / message drafts, clearly **not sent**
- Verifiable source URLs and unanswered questions
- Any GitHub PR link if you actually created one

There is no live ChatGPT-to-conference-agent API endpoint in this repository. GitHub files and reviewed PRs are the proposed asynchronous handoff.
